# Guide du site — Lynette Zoumenou

Ce guide explique comment modifier le site **sans toucher au code**. Tout se passe dans le **panneau d'administration**.

---

## 1. Se connecter

1. Ouvrez votre navigateur (Chrome, Firefox, Safari…).
2. Allez à l'adresse : `http://localhost:3000/admin/`
3. Identifiant : `admin`
4. Mot de passe : `admin123`
5. Cliquez sur **« Se connecter »**.

> Si le mot de passe ne fonctionne plus, demandez-le à la personne qui a créé le site.

## 2. L'écran d'administration

- **À gauche** : le menu avec toutes les rubriques.
- **En haut à droite** : le bouton **« Enregistrer »** (le plus important).
- **Au milieu** : les formulaires à remplir.

## 3. La règle d'or : enregistrer

Après **chaque** modification :

1. Cliquez sur **« Enregistrer »** en haut à droite.
2. Attendez le message « Modifications enregistrées ✔ ».
3. Pour voir le résultat sur le site : ouvrez le site dans un autre onglet, puis appuyez sur **Ctrl + F5** (Windows) ou **Cmd + Maj + R** (Mac). Cette combinaison est obligatoire, sinon le site affiche l'ancienne version.

---

## 4. Profil (photo, nom, description)

Menu **« Profil »** :

- **Nom affiché** → le nom affiché en haut du site.
- **Slogan / accroche** → la petite phrase sous le nom (ex : « Santé · Beauté · Bien-être »).
- **Photo de profil** → cliquez sur **« 📤 Importer »** et choisissez une image sur votre ordinateur (format JPG ou PNG, de préférence carrée).
- **Texte de présentation** → la description « À propos ».
- **Chiffres clés** → les grands nombres (ex : « 12+ ans d'expérience »). Bouton **« Ajouter une statistique »**.
- **Domaines d'expertise** → les petites étiquettes (ex : « Soins naturels »).

## 5. Réseaux sociaux

Menu **« Réseaux sociaux »** :

- Chaque réseau a un **Lien** (commence par `https://…`).
- **Libellé** = ce qui s'affiche en passant la souris (ex : « Facebook »).
- **Réseau** = l'icône choisie.
- Bouton **« Ajouter un réseau »** pour en ajouter. **Laissez le lien vide** pour masquer une icône.

## 6. Services (les cartes cliquables)

Menu **« Services »** :

- **Catégorie** = un groupe (ex : « Coaching »), avec un titre et une icône.
- **« Afficher cette catégorie sur le site »** = cochez pour montrer, décochez pour masquer.
- Dans chaque catégorie, **Offres de la catégorie** = les cartes :
  - **Titre** = le nom (ex : « Renaissance personnelle »).
  - **Sous-titre** = la petite description.
  - **Lien de destination** = la page qui s'ouvre au clic.
  - **Image** = la petite image de la carte (**« 📤 Importer »**).

## 7. E-books (produits digitaux)

Menu **« E-books »** :

- **Titre section digitale** / **Sous-titre** = le titre de la rubrique dans la boutique.
- **Liste des e-books** — pour chaque e-book :
  - **Titre** = le nom.
  - **Type** = « Gratuit » ou « Payant ».
  - **Prix** = ex : `10 $` (pour les payants).
  - **Lien de téléchargement / checkout** = la page d'achat ou de téléchargement.
  - **Popup déclenché** = si un popup doit s'ouvrir au lieu d'un lien (ex : `conte`). Sinon laissez vide.
  - **Couverture** = l'image (**« 📤 Importer »**).
- Tout en bas : **« Bouton Voir tous les e-books »** → **Texte du bouton** et **Lien**.

## 8. Produits physiques

Menu **« Produits physiques »** :

- **Titre section physique** / **Sous-titre**.
- **Liste des produits** — pour chaque produit :
  - **Nom du produit**
  - **Prix** (ex : `12 $`)
  - **Badge** (optionnel, ex : « Nouveau ») — laissez vide pour ne rien afficher.
  - **Lien de la fiche produit** = la page du produit.
  - **Photo** (**« 📤 Importer »**).
- Tout en bas : **« Bouton Visiter la boutique »** → **Texte du bouton** et **Lien**.

## 9. Popups (les fenêtres qui s'ouvrent)

Menu **« Popups »** :

- **Émoji**, **titre**, **badge**, **texte**, **action** (le lien de la liste d'inscription, ex : Systeme.io), les **champs** (prénom, email), le **texte du bouton** et la **note**.
- Un e-book peut déclencher un popup : mettez l'identifiant du popup dans le champ « Popup » de l'e-book.

## 10. Les pages du site

Menu **« Pages »** — il y a 7 pages modifiables :

1. **Appel découverte**
2. **Coaching individuel**
3. **Coaching de groupe**
4. **Formation**
5. **Programme 1 — Reprendre sa place**
6. **Programme 2 — Femmes & Renaissance**
7. **Programme 3 — Oser entreprendre**

Pour chaque page :

- **En-tête de la page** : badge, prix, titre, partie en italique, description, grande image, citation.
- **Piliers** : les petites étiquettes (ex : « Clarté », « Action »).
- **Bouton d'action principal** : **Texte du bouton**, **Lien**, **Note sous le bouton**, **Ouvrir dans** (même onglet ou nouvel onglet), **Popup déclenché**.
- **Formules de paiement** (uniquement certaines pages, ex : Coaching individuel) : nom, prix, lien de paiement, description.
- **Sections de la page** : les listes à puces. Pour chaque section : **Type** (Liste / Citation / Étiquettes), **Titre**, **Icône**, **Couleur des puces**, et les **éléments** de la liste.
- **Phrase de clôture** : l'émoji et le texte final.

## 11. Réglages

Menu **« Réglages »** :

- **Informations du site** : titre du site, nom et email du réalisateur (affichés en bas de page).
- **Apparence** : la couleur du site. Cliquez sur une des 8 couleurs proposées, ou choisissez une **couleur exacte** avec le sélecteur. Toutes les nuances (boutons, bordures, chiffres) sont calculées automatiquement.
- **Textes des onglets** : le nom des 3 onglets (Profil / Services / Boutique).
- **Changer le mot de passe** : tapez l'ancien, puis le nouveau (deux fois). Notez-le quelque part !

---

## 12. Les petites règles à respecter

- **Un lien commence presque toujours par `https://`** — collez-le en entier, sans espace.
- **Ne videz jamais un champ « Lien » par erreur** : cela retire le bouton ou la carte. Si vous vous trompez, ne cliquez pas sur « Enregistrer » ; rechargez simplement la page pour annuler.
- **Ne renommez pas les fichiers d'images** que vous importez : le système s'en charge.
- **Faites toujours Ctrl + F5** sur le site après un enregistrement pour voir le nouveau rendu.
- Pour supprimer un e-book / produit / réseau / popup : utilisez son bouton **✕ Supprimer**, puis **Enregistrer**.

---

*En cas de doute, demandez à la personne qui a installé le site.*
